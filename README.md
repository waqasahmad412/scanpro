# Scan Pro

Scan Pro is a modern Android application designed to provide a simple and efficient document scanning experience.

## Features

- Document scanning
- Image capture and processing
- Clean and user-friendly interface
- Fast document management
- Modern Android UI
- Easy local setup and development

## Tech Stack

- Kotlin
- Android
- Gradle
- Jetpack Components

## Run Locally

### Prerequisites

- JDK
- Android SDK
- Android Emulator or Android Device
